# Traqqr.ai Homebrew Tap

Official Homebrew tap and signed macOS releases for the Traqqr.ai CLI.

## Install

```sh
brew install --cask traqqr-ai/tap/traqqr.ai
```

To update an existing installation:

```sh
brew upgrade --cask traqqr-ai/tap/traqqr.ai
```

To uninstall:

```sh
brew uninstall --cask traqqr.ai
```

Run `traqqr.ai --help` or append `--help` to a command for its current options.
