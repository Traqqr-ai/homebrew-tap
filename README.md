# Traqqr.ai Homebrew Tap

Official Homebrew tap and signed macOS releases for the Traqqr.ai CLI.

## Install

```sh
brew install traqqr-ai/tap/traqqr.ai
```

To update an existing installation:

```sh
brew update
brew upgrade --cask traqqr.ai
```

## Commands

```text
  login                 Authenticate and store a CLI session
  login status          Validate the active CLI session and account
  logout                End the session created by Traqqr.ai CLI login
  accounts list         List the Traqqr.ai accounts you can access
  accounts login-link   Print a login link for one account you can access
```

Run `traqqr.ai --help` or append `--help` to a command for its current options.
